# healthy-recipe-app

A whimsical, Indian-flavor-forward healthy recipe app for deciding what to cook without the daily decision fatigue.

**Tech stack:** React, Vite, TypeScript, Tailwind CSS, React Router.

**Status:** work in progress — V1 (login placeholder, recipe feed with filters, recipe detail, favorites) is up. See `app-v1-spec.md` for scope and `recipe-draft-list.md` for the seed recipe data. More to come.

Live at: https://madhuri-mamilla.github.io/healthy-recipe-app/
